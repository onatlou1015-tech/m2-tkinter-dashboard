🚀 Getting Started

🌟 Instructions:

  1. Open the Python file for the widget you are exploring.
  2. Run the code and observe what happens.
  3. Click, type, and interact with the widgets.
  4. Write down anything you notice or any questions you have.

🔍 Discovery questions:

  • What happens when you click different widgets?
  • Which widgets look similar? Which look different?
  • What information can you see on the screen?

💬 Group Discussion

🗣️ share your discoveries · 20–30 min

Each group prepares:

  • 🌟 Most interesting thing
  • 🤔 Most confusing thing
  • ❓ One question you still have
  • 📱 Real-world app that uses similar widgets
🎯 Discussion questions by widget (click to expand)

✅ Checkbutton: Why use instead of Radiobutton? When to use?

📋 Combobox: Why have read-only & editable? Combobox vs Listbox?

📃 Listbox: Advantage of multiple selection? vs Combobox?

📊 Progressbar: Why show progress? Determinate vs indeterminate?

🔘 Radiobutton: Why only one? How to create different groups?

🎚️ Scale: When better than typing? What makes good design?

🔢 Spinbox: When use instead of slider? Why not just type?

✏️ Entry: Why is input validation important? What happens without?

🎓 Key Concepts Summary

⚡ Event Loop

mainloop() keeps GUI running. time.sleep() freezes it.

📐 Geometry Managers

pack() – stack · grid() – table · place() – exact

📦 Variable Types

StringVar · IntVar · BooleanVar
